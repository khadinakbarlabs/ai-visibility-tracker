# AI Visibility Tracker Support

For help, [open a support issue](https://github.com/khadinakbarlabs/ai-visibility-tracker-docs/issues/new) with public, redacted information only.

Maintained by Khadin Akbar. Include your plugin version, host application, Apify CLI version, the operation you attempted and a short redacted error message. Never include an API token, authentication file, private run URL, raw customer data or a full conversation.

Before reporting a problem, confirm that the official Apify CLI is installed and that you can log in in your own terminal. A chat host without command execution cannot start Actor runs. For Apify account, billing or infrastructure problems, use [Apify support](https://apify.com/contact).

Known limitations: citation results are sampled observations; diagnostic runs do not establish visibility; trends need matching question panels; recurring tracking requires a separate schedule and spending budget.
