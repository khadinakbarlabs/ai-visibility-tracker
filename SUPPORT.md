# AI Search Visibility Tracker Support

For help, [open a support issue](https://github.com/khadinakbarlabs/ai-visibility-tracker/issues/new) with public, redacted information only.

Maintained by Khadin Akbar. Include your plugin version, host application, Apify access route and CLI version when used, the operation you attempted and a short redacted error message. Never include an API token, authentication file, private run URL, raw customer data or a full conversation.

Before reporting a problem, check your connected Apify integration or official CLI login. The route must support the Actor, charge caps and result retrieval; the presence of a connector alone does not establish those capabilities. For Apify account, billing or infrastructure problems, use [Apify support](https://apify.com/contact).

Known limitations: citation results are sampled observations; diagnostic runs do not establish visibility; trends need matching question panels. Recurring setup requires approved cadence/timezone, budgets and duration. Apify schedules collect data; complete automatic reports require verified host agent execution and delivery. Native schedule caps are per action, not a hard monthly portfolio limit. If tracking fails, report only the affected site/module and redacted verification status; never post private profiles or inputs.

You can ask the assistant to prepare a redacted feedback draft describing the workflow, expected/actual result, plugin version and host. Review it before authorizing a public issue. Campaign corrections and usefulness ratings stay private unless you explicitly choose to share them. Never attach full conversations or private campaign exports.
