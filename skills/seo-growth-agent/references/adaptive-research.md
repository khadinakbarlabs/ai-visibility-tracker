# Select research by goal and uncertainty

1. State the accepted goal and website/market/panel. Returning reviews use saved evidence; don't demand a new baseline unnecessarily.
2. Identify the decision evidence could change. Record the observed pattern, plausible explanations, supporting/contradicting evidence and important unknown. A hypothesis is not a measured gap.
3. Check freshness, provenance, panels and coverage; reconcile pending runs first. Stable tracking questions remain fixed; discovery prompts use a separate exploration panel/revision.
4. Select the smallest useful supported check by relevance, uncertainty, feasible action, cost and remaining allocation. Explain without fake numerical precision. Public inspection/export analysis may suffice. Verify live schema/pricing and charge-cap capability before a paid start.
5. Execute only within accepted Actor/module, target, timing and spending scope. For a helpful check outside approval, save the plan and ask for missing scope. Expanded autonomy doesn't authorize charges, added sites, increased frequency or contacting others.
6. Save results and revise hypotheses. Stop when an actionable decision is supported, checks add little, access is insufficient or budget is held/exhausted. Explain remaining uncertainty.

| Question | Useful first step | Conditional follow-up |
| --- | --- | --- |
| Why did citations change? | Paired answers, coverage and cited URLs | Inspect sources/content; authorized matching repeat if useful |
| What should I work on? | Goal, evidence, effort and open actions | One material gap rather than all modules |
| Who competes with us? | Public offering overlap/relevant SERPs | Mapped data if fresh evidence missing and scope permits |
| Where can we earn links/citations? | Relevant sources and existing samples | Qualify publisher fit/useful contribution; no guaranteed gain |
| Did our change help? | Acknowledged implementation and comparable evidence | Matching follow-up, confounders; no automatic causal attribution |

Responsibilities: coordinator owns goal/state/budget; analysts own visibility and competitor/opportunity evidence; action planner owns feasible work/follow-up; report editor owns clear saved outputs; final review checks grounding, scope, costs and comparability. One host can perform these sequentially.
