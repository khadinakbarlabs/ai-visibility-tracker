# Shortest task route

Inspect available files, portfolio state and conversation decisions before asking. A focused request does not need the whole campaign workflow. “Improve” or “fix” describes the object to work on, not automatic permission for collection or publication.

| User intent | Entry | First useful result / acceptance |
| --- | --- | --- |
| Start tracking my site; add another website | visibility-onboarding | Unmeasured profile/panel with sourced facts, labelled assumptions and only consequential user-side blockers |
| Import this citation export; audit whether AI cites my pages | ai-visibility-tracker | Observed/planned coverage, citation rate among observed checks, missing answers explicit, one supported action |
| What changed between these two checks? | visibility-trends | Matching-tuple denominator and gains/losses; unmatched checks and changed panels separate |
| Who outranks me? Compare competitor traffic | competitor-intelligence | Competitor evidence and rank/traffic table; estimates and observations distinguished |
| What keywords should I target? Review this keyword file | keyword-opportunities | Prioritized evidence-linked terms; unavailable volume/difficulty stays unknown |
| Is interest rising or seasonal? | search-trends | Comparable normalized interest; no inferred absolute search volume |
| Compare our backlink exports | competitor-backlinks | Referring-domain/sample gaps with coverage limitations |
| Which publishers might cite or link to us? | link-opportunities | Qualified prospects with evidence; no sent outreach |
| Build a content brief; improve this page from evidence | visibility-action-plan | Reviewable draft/brief and acceptance criteria; publication and implemented outcomes remain separate |
| Review advice; correct audience; I completed this | visibility-action-plan or seo-growth-agent | Scoped feedback/action transition; preserve other sites, rejects and history |
| Fix an interrupted run/download | ai-visibility-tracker plus operation receipt | Same run ID/next offset or explicit unresolved submission; no duplicate launch |
| Continue; review my portfolio this week | seo-growth-agent | Reconciled accepted goal, partial work/blocker and one feasible next action |
| Schedule, pause, resume recurring tracking | scheduled-visibility-tracking | Capability/configuration/execution/report/delivery proof separated |
| Release this page/report | visibility-action-plan | Reviewable artifact; act only with publication authorization and a capable host |
| Build/fix/release a plugin, app or extension; humanize text | Host's relevant development/writing workflow | No SEO collection unless separately requested; a product keyword alone is not a trigger |

For saved data, detailed Actor access instructions are unnecessary until fetching is requested. Import means inspect a read-only copy, validate structure, preserve the original and provider fields, then derive a labelled view. Do not pretend an unverified export is an authenticated live result. A generic backlink/keyword file must not be interpreted as AI citation rows. If the file type is ambiguous, inspect available headers/rows first; ask only if the ambiguity still changes the analysis.

For a new run, the first outcome can be an unmeasured small panel while access/spend are unresolved. For interrupted work, the first outcome is a recovery checkpoint, not another launch. See [receipt contract](operation-receipt.md) and [campaign continuity](campaign-state.md). Report one concrete next action; do not make every available module an onboarding requirement.
