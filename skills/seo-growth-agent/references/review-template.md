# Saved review format

Use actual evidence. Bracketed fields are placeholders, not sample results. Keep the first screen concise with linked evidence. Preserve website/market/panel IDs, dates and missing coverage.

## Website review

**What changed:** [Matched-panel change or no newer evidence.]
**Why it matters:** [Business implication and confidence/limitation.]
**Next useful work:** [At most three actions, explained tradeoffs.]
**Next check:** [Approved occurrence or proposed follow-up; distinguish.]
**Needs your input:** [Only unresolved access, spending or consequential preferences.]

Include relevant evidenced modules:

- Google keyword table/history: query, sampled rank/depth, page, prior position/date, market/device; first-party aggregated metrics separately.
- AI question/platform matrix: cited/not cited/unknown, observed denominator, paired comparisons and source URLs. No unsupported mention/sentiment metrics.
- Competitor/opportunity cards: observed gap/publisher fit, evidence/date, effort, confidence and draftable contribution; provisional prospects labelled.
- Action queue: ID, work/status, rationale/evidence, feedback, implementation verification/date and follow-up result. Subsequent change doesn't prove causation.
- Operations: coverage/freshness, pending runs, charges/reservations, next authorized work, configuration/execution/report/delivery proof and pauses.

Weekly digests show changes, open/completed work, next three priorities, missing evidence and next check. Monthly reviews select research by goal, not every module automatically. Changes-only monitors save quietly without actionable change. Alerts need accepted thresholds, adequate comparable coverage, deduplication and approved destination; no arbitrary percentage alarms for tiny samples.

Use accessible text beside color. Interactive filters/controls require host support; otherwise offer familiar commands/readable tables/private exports. No remote scripts/web service. Save Markdown, supported visual artifacts, observations, action/history updates and latest report pointer; chat output alone doesn't prove persistence.
